# MC RepeateBboard Rakovo Mámy
> Just FYI, this project isn't as polished as my other ones. Pleasse be minfull of that when ordering.  

Custom DPS to implement an E22P-868M30S module which is very nice.  
It features a 1W of output power MPPT charger, thoughtfully designed power rail and fitering. Place for a RTC clock.  
And PIC uC power management to take care of everything.  

### Motivation
So after TvojeMama showed out his MC repeater board, Radek thought about improvements. So he drew up the schematic, but he didn't have time to finish it so I've stepped in to routing the board so it can be finished.  

## Firmware
The pinout is the same as on the generic nrf52 board.
